# LOOM reusable module: Footer Bar

Three-row footer composition:

1. Project Branding
2. More Tools / Orb Dock
3. LOOM Attribution

The whole footer now defaults to `fit-content`. Project branding/logo remains centered by default. Each row still owns independent width, alignment, padding, radius, and background settings, so projects can freely expand or reposition any row through Admin.

## 0.12.05 starter default

The whole footer defaults to **full width**. Only the project-branding row defaults to **fit-content** and centered. Both remain independently Admin-configurable.
