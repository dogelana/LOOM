# LOOM Session Replay Capture Foundation — 0.12.08

Projects capture a lightweight interaction stream: taps/pointers, throttled cursor movement, scroll positions, navigation viewport state, safe input changes and selected navigation keys. Password/secret/auth fields and any subtree marked `data-loom-private` or `data-loom-sensitive` are masked or omitted at capture time. Replay retrieval is Admin-only. This release captures data; a full visual Replay Studio is intentionally deferred.
