# LOOM Design System Foundation — 0.12.08

`engine/loom-design.css` defines global tokens for surfaces, typography, spacing, radii, shadows, controls, focus states, touch minimums and motion preferences. Existing modules are not force-rewritten; they can migrate progressively onto these stable tokens/components.
