# LOOM Performance & Cache Discipline — 0.12.08

Registry responses now use deterministic ETags and session cache revalidation. Module discovery polling is less aggressive while remaining hot-reload capable. Static assets continue content-hash cache busting. Live identity, project state and runtime data remain no-store and are never treated as static cache.
