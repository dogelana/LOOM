# Green Beans Project Changelog

## 0.4.0 — Meal Creator

- Added the Green Beans **Meal Creator** project module.
- Build named meals from existing Shopping List ingredients or add new comma-separated ingredients while creating/editing a meal.
- Missing meal ingredients are automatically added to Shopping List.
- Meals project themselves into Shopping List as first-class meal groups; edit/rename keeps the group synchronized and removing a meal dissolves only the group while preserving ingredients.
- Added Shopping List **Add as Meal** and **Shift + Enter** quick-create integration whenever Meal Creator is installed.
- Meal membership is independent of manual Shopping List groups and supports the same ingredient appearing in multiple meals.

## 0.3.1 — Ambient Identity Upgrade

- Increased the default ambient field density through the reusable LOOM background-energy module.
- Kept Green Beans pea-pod artwork as the regular project particle override.
- Added an occasional carrot (`🥕`) as the Green Beans special-particle override.

## 0.3.0 — Shopping List Foundation

- Added the first standalone Green Beans feature module: Shopping List.
- Add one item or comma-separated items, edit/remove items, and toggle completion.
- Added named groups, multi-select grouping, ungrouping, whole-group completion, and group management.

## 0.2.0 — Project Identity + Green Beans Avatars

- Added Green Beans project identity overrides for username and profile picture.
- Added the supplied Green Beans default avatar, String Bean / Bean Pod creator choices, background color, and Ball Cap headwear.
- Added dedicated trait icons for None and Ball Cap.

## 0.1.0 — Green Beans Project Shell

- Established Green Beans as a LOOM-powered project with project-owned logo, logo text, branding, avatar provider, and background-orb provider.
