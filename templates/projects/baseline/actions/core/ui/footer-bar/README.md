# LOOM reusable module: Footer Bar

v0.11.23 uses a three-row footer composition:

1. Project Branding
2. More Tools / Orb Dock
3. LOOM Attribution

Each row has independent width, alignment, padding, radius, and background settings. The More Tools row defaults to fit-content so it grows only as large as its actual orb content, up to the available viewport width.
