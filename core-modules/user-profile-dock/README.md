# LOOM reusable module: Profile Dock

Captures `core.user.profile` from normal project flow and places a `👤 User Profile` launcher in the built-in LOOM project shell.

The shell itself remains usable without this module. Installing Profile Dock only changes where User Profile is presented; it does not replace the profile data or profile module.
