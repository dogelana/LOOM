# Project Loader · release-managed core

As of LOOM 0.15.14, `core.ui.loader` is a release-managed project-scoped core module. Existing project-local loader copies are treated as legacy defaults and suppressed when this core implementation is present.

Loader wordmark text, colors, and font come from canonical Project Identity branding. Disabling or customizing the Header Wordmark module does not change loader branding.
